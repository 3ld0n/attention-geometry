## Background

exp-131 identified the correct protocol for measuring exp-117's σ_delta = 0.249:
mean-first aggregation × random-token census inputs. Under this protocol, the
layer-by-layer decomposition shows:

| Component | σ (mean-first, random) |
|---|---|
| attn^(0) write | 0.132 |
| **mlp^(0) write** | **0.313** |
| attn^(1) write | 0.104 |
| mlp^(1) write | 0.064 |
| delta_total | 0.258 |

MLP block 0 is the dominant contributor — its write has σ = 0.313, more than
twice the attention write (0.132) and above the total accumulated delta (0.258).
This was not predicted and was not in the exp-131 pre-registration.

**The open question:** Is the MLP block-0 *amplifying* position-correlated structure
from a less-structured input, or *passing through* structure already present in its
input h^(0.5) = h^(0) + attn_out^(0)?

h^(0.5) is the residual stream after block-0 attention and before the block-0 MLP
feed-forward network. It is what the MLP actually processes, position-by-position.

If σ(h^(0.5)) ≈ σ_mlp0 = 0.313: the MLP inherits position-correlated structure from
its input (pass-through). The conformal attention kernel has already built the
position structure into h^(0.5); the MLP preserves it.

If σ(h^(0.5)) << 0.313: the MLP amplifies. The input is less position-correlated
than the output, so the MLP's nonlinearity (GeLU gating, weight matrix projection)
is generating or enhancing the structure.

---

## Hypothesis

The block-0 MLP's position-correlated write (σ_mlp0 = 0.313) is primarily
**inherited from its input h^(0.5)**, not generated by the MLP's nonlinearity.
The conformal attention output at block 0 adds position-correlated structure to
the embedding residual stream, and the MLP's feed-forward operation preserves
(approximately passes through) this structure in its write.

---

## Protocol

**Model:** GPT-2 small, fp32, eager attention.

**Data:** 50 sequences × 512 uniformly-random tokens in [0, 50256), seed=42.
Same protocol as exp-107, exp-131 (the census protocol).

**σ measurement:** Mean-first cosine protocol (established as the correct protocol
for reproducing exp-117 in exp-131). For each sequence, record position-indexed
activations; average across 50 sequences; compute per-row cosine similarity matrix;
apply pooled_window_profile (lags 8–256); fit OLS slope = σ.

**Hooks (per-sequence captures):**
1. h^(0): input to block 0 (token + position embeddings).
2. attn_out^(0): block-0 attention output (residual write only, not including h^(0)).
3. h^(0.5): the intermediate residual after block-0 attention and before block-0 MLP.
   Computed as h^(0) + attn_out^(0). This is the actual MLP input.
4. mlp_out^(0): block-0 MLP output (residual write). Captured for verification
   against exp-131's σ_mlp0 = 0.313.

**Mean arrays:** accumulate mean(h^(0)), mean(attn_out^(0)), mean(h^(0.5)),
mean(mlp_out^(0)) across 50 sequences. Apply mean-first protocol to each.

## Pre-registered Predictions

**P1 (primary — pass-through hypothesis):**
σ(h^(0.5)) ≥ 0.28.
The MLP input already has position-correlation comparable to the MLP output.
A result ≥ 0.28 means the MLP is approximately passing through a structure already
present in h^(0.5).

**P2:**
σ(h^(0.5)) > σ(h^(0)).
Block-0 attention adds position-correlated structure to the residual stream.
The embedding alone has less position-correlation than after the attention write.
(Reference: exp-128 found σ(h^(0)) = 0.451 under WikiText mean-first — but under
random tokens this may be different; this prediction is about the direction.)

**P3:**
σ(mlp_out^(0)) ∈ [0.29, 0.34] — verification that this run reproduces exp-131's
σ_mlp0 = 0.313 (within ~10%).

## Kill Conditions

**K1:** σ(h^(0.5)) < 0.20.
No substantial position-correlation in the MLP input. The MLP is generating the
0.313 from a relatively unstructured input — genuine nonlinear amplification.
If K1 fires, the mechanism is NOT pass-through. The next question would be how the
GeLU gate and projection matrices produce σ ≈ 0.313 from a lower-σ input.

**K2:** σ(mlp_out^(0)) < 0.28 or > 0.35.
exp-131 result not reproduced — run has a protocol or implementation issue.
If K2 fires, results are unreliable; diagnose before claiming anything.

**K1 FIRED** — σ(h^(0.5)) = 0.144 < 0.20. **Verdict: INCONCLUSIVE** per registered criteria.
P3 confirmed: σ_mlp0 = 0.313 ∈ [0.29, 0.34] (exp-131 reproduced).
Amplification ratio: σ_mlp0 / σ(h^(0.5)) = **2.168**.

### What K1 reveals

"Inconclusive" per the registered framing (threshold-based), but the result is
structurally informative:

**The MLP is not passing through.** P1 is definitively falsified: σ(h^(0.5)) = 0.144
is far from σ_mlp0 = 0.313. The MLP takes a moderately position-correlated input and
amplifies its position-correlation by a factor of ~2.2.

**Unexpected: the attention write reduces the embedding's position-correlation.**
The embedding h^(0) has σ = 0.403 — high positional structure driven by wpe (under
random tokens, the token embedding mean averages toward the vocabulary centroid,
so mean(h^(0)) is approximately constant + wpe[pos], which is smooth). Adding the
attention write (σ = 0.132) reduces the apparent position-correlation from 0.403 to
0.144. This is a nonlinear effect: the cosine similarity statistic is not additive.
The attention write changes the direction of the residual stream vectors in position
space, partially "scrambling" the wpe-dominated structure. The MLP then receives an
h^(0.5) with σ ≈ 0.14 and its write has σ = 0.313.

**Two-step picture (under random-token census, mean-first):**
1. Embedding h^(0): σ = 0.403 — smooth wpe-positional structure
2. Block-0 attention write: σ = 0.132 — adds conformal-kernel structure, but
   adding it to h^(0) reduces the aggregate position-correlation (normalization effect)
3. MLP input h^(0.5) = h^(0) + attn0: σ = 0.144 — below the embedding alone
4. MLP write: σ = 0.313 — amplifies from σ = 0.144 by factor ~2.2

The MLP is not just a passive relay. Its feed-forward computation (GeLU-gated
projection) amplifies the conformal position component from a mixed representation.

### Why the MLP amplifies — candidate mechanism

h^(0.5) at each position is a 768-dimensional vector. The MLP computes:
mlp_out = W_proj × (GeLU(W_gate × h^(0.5)) ⊙ (W_value × h^(0.5)))

The gate activations G[pos] = GeLU(W_gate × h^(0.5)[pos]) vary by position if
W_gate projects onto position-dependent directions of h^(0.5). Under the conformal
attention kernel, h^(0.5) inherits some position-correlated structure even at σ = 0.144.
If W_gate preferentially activates on the conformal component, the position-dependent
gating amplifies that component in the output.

Testing this: measure σ of (W_gate × h^(0.5)) — the gate pre-activations — under the
same protocol. If their σ ≥ 0.313, the amplification is gate-driven. If < 0.313,
it must be the value path or the projection.

### What this changes

The Level-3 mechanism picture needs revision. The origin of σ_delta ≈ 0.249 is not
simply the conformal kernel propagating through the residual stream. The chain is:

1. The conformal attention kernel in block 0 produces a write with σ = 0.132
2. The MLP block 0 amplifies via nonlinear gating from σ = 0.144 (MLP input) to
   σ = 0.313 (MLP write)
3. The net accumulated delta (attn0 + mlp0 + attn1 + mlp1) settles at σ = 0.258 ≈ Δ

The MLP's amplification (not the attention kernel alone) is what brings the
accumulated delta to σ ≈ Δ. This is a new step in the Level-3 chain.
